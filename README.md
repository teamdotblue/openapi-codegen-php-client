# team-blue/java-openapi-codegen-php-client

A library to create a PHP client based on an OpenApi spec.

Built on OpenAPI Generator (Java). It generates a PHP HTTP client — endpoints, models, `ClientBuilder` with PSR-18/HTTPlug support — from an OpenAPI specification, including team.blue conventions for value objects and JSON-immutable objects via [`team-blue/php-json-immutable-objects`](https://github.com/teamdotblue/php-json-immutable-objects), [`team-blue/php-util`](https://github.com/teamdotblue/php-util) and [`team-blue/php-client-mock`](https://github.com/teamdotblue/php-client-mock) integration.

## Installation

```bash
composer require team-blue/java-openapi-codegen-php-client
```
